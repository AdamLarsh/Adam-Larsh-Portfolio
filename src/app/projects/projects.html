The Speed's Kneeds - Car Dealership Database

For a java project in school I was tasked to make a database program that could Create, Read, Update and Delete (CRUD). My partner and I worked on this project to create a program that can keep track of records and display a chart of statistics. The program let the user keep track and create employee data, customer data, sales and products in the inventory.

My tasks in the project was to make the buttons to add, update and delete function, make the UI screen for the database login pack, as well as the CSS and the pretty tables the displayed the items in the table.

Inventory items that are stored in the table have their brand, model, colour, condition, year, mileage and price tracked. Sales that are made track the employee that made the sale, the customer that made the purchase and the inventory item that is being sold. In the statistics tab there is a pie chart that will display a chart based on the colour of cars in the inventory.

Monster Clicker Adventure - Idle Clicker Game

For a final project in Java we were tasked to make either a game or an application, my group and I picked a game and made a clicker game. The game was a simple clicker game where you click the monster to damages it and once it's killed it gives you gold. Gold will then let you go into the shop and purchase sword upgrades so you dealt more damage per hit.

There is 10 different levels in the game and they get harder as you go with the monsters getting more health. At the beginning there is about 6 monsters in the stage with the final one being a boss and as the levels go higher there is more monsters before the final boss. Once the game is over a final screen will show which ends the game.

I was tasked to make the saving and loading feature so players could save and load their progress, making the actual game work when you click a monster they take damage, making the levels work and when monsters die it switches to the next monster or boss as well as the balancing to the game to make it fair and fun to progress.

Painting Program - For Fun

In my high school class I was ahead of everyone so for fun I made a painting program. It was a tricky challenge to start making since this was my first real big project but my teacher help me tons in making it. It was made in an IDE called Processing and it uses mouse position checking to determine where the user is with the mouse. The program has set shapes the user can draw with including a line tool where the left clicks sets point A and right clicks to draw a straight line from point A to B.

The user has a selection of predetermined colours but the user can also pick their own using the colour wheel and switch off and be able to select the previous colour they custom made until they pick a new custom colour. On the right of the program the user can also pick the size of the shape and the opacity the shape will be (Although opacity doesn't work that well).
